HTML и CSS

HTML — это язык разметки, который используется для создания и структурирования веб-страниц. С помощью HTML можно создавать заголовки, абзацы, списки, таблицы, изображения и гиперссылки. CSS используется для оформления внешнего вида HTML-документа. С помощью CSS можно изменять расположение, размеры, цвета и другие свойства элементов. HTML отвечает за структуру страницы, а CSS — за её оформление. HTML-документ состоит из различных элементов. Элементы создаются с помощью тегов. Для создания заголовков используются теги h1, h2 и другие заголовки. Для создания абзацев используется тег p. Изображение добавляется с помощью тега img, а адрес изображения указывается в атрибуте src. Гиперссылки создаются с помощью тега a, а адрес страницы указывается в атрибуте href. Для создания маркированного списка используется тег ul, а отдельные элементы списка создаются с помощью тега li. Таблицы создаются с помощью тегов table, tr, th и td. CSS позволяет управлять внешним видом HTML-элементов. CSS использует селекторы и свойства. Например, с помощью свойства text-align можно выравнивать текст. Flexbox используется для создания гибких макетов и расположения элементов страницы. HTML и CSS вместе позволяют создавать полноценные веб-страницы.
